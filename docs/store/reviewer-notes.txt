YTTS is a single-purpose transcript reader for youtube.com. On a watch page the content script opens the site's own transcript panel in the background, reads the rendered transcript, closes the panel again if YTTS opened it, and shows the text in a card. Transcript text stays in page memory and is written to the clipboard only on the user's Copy click. chrome.storage.sync holds three display preferences. No backend, telemetry or analytics; all JavaScript is bundled.
