YTTS is a single-purpose transcript reader for youtube.com. The content script reads the transcript that YouTube's own transcript panel renders for the current video (it opens that panel invisibly and closes it again) and shows it in a card on the page. Transcript text stays in page memory and is written to the clipboard only on the user's Copy click. chrome.storage.sync holds three display preferences. There is no backend, telemetry or analytics, and all JavaScript is bundled in the package.
