适用于 Microsoft Edge 的 YTTS 在视频旁显示转写文稿，方便你阅读并一键复制。你可以按原始字幕行、分组后的句子或连续文本阅读。点击某一行或句子，即可跳转到视频中的对应时刻。整个转写文稿可复制为纯文本，并可选择是否包含时间戳。

在观看页面上，根据需要展开“转写文稿”卡片，阅读说明后点击“允许读取转写文稿”。此后，YTTS 会在需要时于后台打开 YouTube 的转写文稿面板，读取其中显示的文本；如果面板由 YTTS 打开，则会将其关闭。Microsoft Edge 会为此次安装记住这一选择，因此之后打开的观看页面会加载转写文稿。

转写文稿保存在标签页内存中。只有当你点击“复制”时，YTTS 才会将文本写入剪贴板。Microsoft Edge 会在本地保存你的同意，并保存三项显示偏好；如果已开启设置同步，这些偏好可能通过你的浏览器账号同步。YTTS 免费且开源，无广告、无需账号，也没有后端、分析或遥测功能。

视频需要有 YouTube 以转写文稿形式提供的字幕。卡片会使用网站的界面语言，并与网站的浅色和深色主题保持一致。

YTTS 是独立项目，与 YouTube、Google 或 Microsoft 无关联。
