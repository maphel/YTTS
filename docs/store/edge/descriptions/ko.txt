Microsoft Edge용 YTTS는 동영상 옆에 스크립트를 표시하여 읽고 클릭 한 번으로 복사할 수 있게 해 줍니다. 원래 자막의 줄, 묶인 문장 또는 이어지는 텍스트로 읽을 수 있습니다. 줄이나 문장을 클릭하면 동영상의 해당 시점으로 이동합니다. 전체 스크립트를 일반 텍스트로 복사하고, 타임스탬프 포함 여부도 선택할 수 있습니다.

동영상 시청 페이지에서 필요하면 스크립트 카드를 펼치고, 안내를 읽은 뒤 «스크립트 허용»을 클릭하세요. 그러면 YTTS는 필요할 때 YouTube의 기본 스크립트 패널을 백그라운드에서 열어 표시된 텍스트를 읽습니다. YTTS가 연 패널은 읽은 뒤 닫습니다. 브라우저가 이 설치에서 선택한 내용을 기억하므로 이후 시청 페이지에서는 스크립트가 불러와집니다.

스크립트는 탭의 메모리에만 유지됩니다. YTTS는 사용자가 «복사»를 클릭할 때만 클립보드에 기록합니다. 브라우저는 동의를 로컬에 저장하고 세 가지 표시 설정을 저장합니다. 표시 설정은 브라우저 계정을 통해 동기화될 수 있습니다. YTTS는 무료 오픈 소스이며 광고, 계정, 백엔드, 분석 또는 원격 측정 기능이 없습니다.

동영상에 YouTube가 스크립트로 제공하는 자막이 있어야 합니다. 카드는 사이트의 인터페이스 언어를 따르며 밝은 테마와 어두운 테마에 맞게 표시됩니다.

YTTS는 독립적인 프로젝트이며 YouTube 또는 Google과 관련이 없습니다.
